# Production Setup - Fix Server Error

## ❌ Current Issue:
Your frontend shows "ERROR 3800948228" because it can't connect to the backend API.

## ✅ Solution: Add CORS Environment Variable to Render

### Step 1: Go to Render Dashboard
https://dashboard.render.com

### Step 2: Click Your Backend Service

### Step 3: Click "Environment" Tab

### Step 4: Add This Variable

Click "Add Environment Variable" and add:

**Key:**
```
CORS_ALLOWED_ORIGINS
```

**Value:**
```
https://www.orikwebcraft.com,https://orikwebcraft.com,http://localhost:3000
```

### Step 5: Click "Save Changes"

Render will automatically redeploy.

---

## 🔍 What This Does:

- Allows your frontend (www.orikwebcraft.com) to connect to the backend
- Fixes the CORS (Cross-Origin Resource Sharing) error
- Backend will accept API requests from your domain

---

## ⏱️ After Adding:

1. Wait 2-3 minutes for Render to redeploy
2. Visit https://www.orikwebcraft.com
3. The error will be gone!
4. Your website will load properly

---

## 📋 Current Required Environment Variables on Render:

```
CORS_ALLOWED_ORIGINS = https://www.orikwebcraft.com,https://orikwebcraft.com,http://localhost:3000
DEBUG = False
SECRET_KEY = [auto-generated by Render]
```

**That's it! Just add CORS_ALLOWED_ORIGINS and the frontend will work!** 🚀

## ✅ How to Verify It's Working:

1. Open browser console (F12)
2. Go to https://www.orikwebcraft.com
3. Check the Network tab
4. You should see successful API calls to your backend
5. No more CORS errors!
